### 1. OAK V5 ROOT FLARE & GROUND CONTACT (DEFECT #1)

#### A. Initial Defect Description
- In Gate B baseline, the Oak V5 sprite was split into dual passes using straight horizontal bounding boxes:
  - `rootMask.rect(-600, trunkGroundY - 8, 1200, 1000)`
  - `trunkMask.rect(-600, trunkGroundY - 950, 1200, 962)`
- Because the subterranean terrain has a naturally undulating surface elevation profile generated by `terrainData.getSurfaceY(worldX)` ($\pm 22\text{px}$ sinusoidal contour), a flat horizontal cutline produced an artificial straight edge across the root buttress flare.

#### B. Remediation Implemented
- In [WorldIntegrationScene.tsx](file:///c:/Users/ADMIN-PC/Documents/ANTIGRAVITY/GAME/.worktrees/task-021-world-integration/the-vivarium-web/src/components/WorldIntegrationScene.tsx):
  - **Pass 1 (Root Mask):** Converted from flat rectangle to an undulating polygon that samples `terrainData.getSurfaceY(mx) - 6px` every $16\text{px}$ across $X \in [-600, +600]$. The root cluster remains strictly subterranean behind the solid soil mesh.
  - **Pass 2 (Trunk Mask):** Converted from flat rectangle to an undulating polygon that samples `terrainData.getSurfaceY(mx) + 10px` across $X \in [-600, +600]$. This provides a $+10\text{px}$ organic buttress overlap that embeds naturally into the turf without exposing uncarved root tips.
- **Verification Result:** Zero straight cutline artifacts; trunk base blends seamlessly into grass rim.

### 4. LAKE BASIN BLACK BOX & WATERFALL VERTICAL CUTS (DEFECT #4)

#### A. Initial Defect Description
- In `AquaticRenderer.ts`:
  1. `renderWaterfall()` drew backdrop rock and sheer veil using rigid `roundRect(..., 8)` and `roundRect(..., 4)`.
  2. `renderLakeBasinAndSediment()` anchored bottom sediment mud to rectangular corners: `(maxX + 10, bottomY + 40)` and `(minX - 10, bottomY + 40)`.
- This created harsh black vertical lines and a rectangular block juxtaposed against organic terrain.

#### B. Remediation Implemented
- In [AquaticRenderer.ts](file:///c:/Users/ADMIN-PC/Documents/ANTIGRAVITY/GAME/.worktrees/task-021-world-integration/the-vivarium-web/src/aquatic/AquaticRenderer.ts):
  - **Waterfall Gorge Rock Contour:** Replaced `roundRect` with an organic 32-point polygon (`gorgePts`) featuring natural sinusoidal side taper ($width \times 0.25$) and harmonic micro-waviness ($\sin(t \times 8) \times 3$), emulating water-eroded dark wet riparian slate (`#18222d`, $\alpha=0.88$).
  - **Waterfall Sheer Veil:** Replaced rigid box with contoured tapering drape polygon (`veilPts`) with soft flare ($width \times 0.15$) and translucent veil fill (`#2a6f97`, $\alpha=0.30$).
  - **Lake Basin Sediment:** Replaced the box bottom corners with a smooth sinusoidal return curve that follows the natural parabolic bowl profile ($baseY + 36\text{px} + \text{depthFactor} \times (\text{maxDepth} - 6\text{px})$), eliminating all rectangular box corners.
- **Verification Result:** Zero rectangular borders; lake basin and waterfall gorge blend organically into subterranean cavern geometry without introducing synthetic external artwork.
